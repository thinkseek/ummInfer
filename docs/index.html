引擎

统一编排

同一引擎内运行 VLM、ASR、图像与语音生成：共享会话、任务编排、流式事件，文本行为保持兼容，多模态输出按需启用。

流式与取消

C++ 核心与 ZeroMQ / MessagePack 通信，HTTP JSON、SSE、WebSocket 与 CLI 公开接口，统一的回调顺序、取消与错误语义。

原生客户端

macOS SwiftUI 原生客户端，流式对话、录音与播放、原生过渡动效；另有单文件 Web 客户端便于快速验证。

真实基线

统一 benchmark 覆盖转写、数学推理、视觉问答与音图联合输入，全部指标来自真实模型实测，可复跑、可核对。
