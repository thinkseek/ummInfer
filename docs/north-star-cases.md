# ummInfer 理想态标杆用例集（以终为始进度标尺）

> 本文固化 ummInfer 面向 [vision.md](vision.md) 终局愿景的 **8 个端到端黄金标杆用例（NS-01 ~ NS-08）**，作为后续所有工程迭代、硬件验收与进度衡量的唯一北极星标尺。

---

## 核心交互原则：客户端零手工控制（Zero Manual Modality Controls）

- **用户不需要在客户端手动开关模态或调底层参数**：打开 Web UI 或 macOS `ummmlx` 即可直接说话、打字、发图或发视频，**不需要**用户自己决定“这轮开不开图 / 开不开视频 / 选哪种抽帧策略”。
- **自主路由归引擎与模型**：由后端模型与引擎默认自主判断何时仅回答文本/语音、何时原位插入示意图、何时生成动态视频；客户端只负责**自然输入**、**流畅无跳动渲染**，以及**极简轻交互**（随时语音插话打断、点击任意静图原位触发 `Animate → Video`、会话导出/导入）。
- 现有开发者高级选项（如帧预算、调试参数）仅保留为可选/折叠或协议级字段，绝不作为默认用户心智负担。

## 黄金标杆用例（NS-01 ~ NS-08）

### NS-01｜活教材：单流图文视音交错讲解
- **输入**：用户默认配置下直接文字或语音提问——*“用通俗方式讲清黑洞吸积盘和引力透镜，配示意图和动态演示”*（客户端零手工模态开关）。
- **理想态输出**：
  - `< 0.8s` 首字 Markdown，`< 0.8s` 同步开启自然连贯的流式语音播报；
  - 讲到关键节点，正文流内原位出现 `slot-0` 清晰结构示意图（`< 2s`）与 `slot-1` 以 `slot-0` 为首帧锚定的原生 I2V 动态模拟视频（`< 5s`，首帧无缝衔接、无拉伸、运动物理感合理）；
  - 正文、配图、视频、旁白共享同一叙事逻辑，无原始 tag 泄漏、无排版跳动、无多轮 Agent 等待停顿。
- **硬验收指标**：`TTFT < 0.8s`、`TTFA < 0.8s`、首图 `< 2s`、I2V 视频 `< 5s`、首帧与静图视觉连贯、0 协议/tag 泄漏、真人盲评无明显割裂。

### NS-02｜原位静图一键转视频 & 视觉迭代
- **输入**：承接 NS-01 中任意已生成静图（覆盖 **16:9 横屏 / 9:16 竖屏 / 1:1 方形**），用户在客户端直接点击静图上的 `Animate → Video`（`POST /v1/visual/render`），或中途取消后立即重试。
- **理想态输出**：
  - 静图原位平滑切换为匹配原宽高比的动态视频（无拉伸变形、首帧与静图肉眼一致、`< 5s` 可播）；
  - 中途取消 `< 0.5s` 响应且原静图无损保留，`in_flight` 归零，紧接着重试 100% 成功。
- **硬验收指标**：3 种宽高比均无拉伸、取消响应 `< 0.5s`、取消后零残留事件且重试 100% 成功、互动预览耗时 `< 5s`。

### NS-03｜自主模态路由（零客户端控制，该文则文、该图则图、该动则动）
- **输入**：同一默认客户端状态（用户不切任何开关），连续发起 4 类请求：
  1. 纯推导/代码题（*“证明素数有无穷多个”*）
  2. 静态空间/结构题（*“画出 Transformer 掩码注意力结构图”*）
  3. 动态过程题（*“演示双摆混沌运动的演化”*）
  4. 细节追问（*“把刚才第二步展开说明”*）
- **理想态输出**：
  - ①④ 仅输出文字与语音（**0 图 0 视频**）；
  - ② 输出文字 + 1 张清晰静图（**0 视频**）；
  - ③ 输出文字 + 示意图 / 原生动态视频；
  - 全程客户端无需用户切换任何模态按钮。
- **硬验收指标**：4 类场景决策准确率 ≥ 90%（理想态 ≥ 95%），冗余出图/出视频率 `< 5%`。

### NS-04｜全局全双工语音 + 毫秒级随时打断（Barge-in）
- **输入**：Web UI 或 macOS `ummmlx` 通过 `/v1/realtime` 语音提问（*“详细介绍太阳系八大行星”*）；系统外放语音播报到第 3 秒时，用户直接插话 *“停一下，直接讲土星环”*，2 秒后再插话 *“换成英文讲”*。
- **理想态输出**：
  - 扬声器外放回声 **0 误打断**；
  - 用户开口后 `< 300ms` 静默旧播报并中止旧 VLM/TTS/视觉子任务，`< 800ms` 响起新回答首音；
  - 对话历史精确截断在用户实际听到的游标位置（`playback_ack`），自然承接新意图，无旧音频残留、无断连、无复读。
- **硬验收指标**：外放回声误触发率 `0%`、打断到静默 `< 300ms`、新首音 `< 800ms`、多轮历史截断 100% 精确、高并发慢读 0 reset。

### NS-05｜看真实长视频 + 语音实时共创
- **输入**：用户上传一段 **1–3 分钟真实实拍自然视频**（多镜头、含人物/物体动作变化），边看边语音问 *“刚才画面里发生了什么变化？”*，不等讲完直接语音打断：*“把那个场景改成赛博朋克夜景并动起来”*。
- **理想态输出**：
  - 真实视频解码 + prefill `< 2–3s` 开启语音回答，准确描述真实动作与镜头变化；
  - 打断后结合视频上下文直接生成风格化新图与 I2V 动态片段，单对话流无缝闭环。
- **硬验收指标**：真实自然长视频问答准确率高且无幻觉、视频首响 `< 3s`、打断后跨模态生成成功且贴合视频内容。

### NS-06｜交互式分镜：跨槽位角色与画风一致性
- **输入**：上传 1 张草图或主角参考图 + 语音描述：*“做 3 个镜头的短片分镜：镜头 1 主角推开雨夜咖啡馆门，镜头 2 坐窗边看表，镜头 3 转身微笑，配旁白”*。
- **理想态输出**：
  - 连续产出 3 段分镜脚本 + 3 张**同一主角/一致画风与光影**的关键帧 + 对应原位 I2V 动态预览 + 连贯配音；
  - 跨槽位人物外貌、服装与场景色调保持一致，不出现每帧换脸。
- **硬验收指标**：3 镜头角色/风格一致性人工评测通过、首帧锚定连续性无跳变、端到端单流或连续两轮完成。

### NS-07｜多用户并发、故障隔离与长稳韧性
- **输入**：5 卡常驻生产服务上，6 路混合并发（文本 + 图文视交错 + 全双工语音 + 视频输入 + 随机 `/abort` + 非法尺寸/损坏音频注入），持续运行 30 分钟。
- **理想态输出**：
  - 0 进程崩溃、0 显存泄漏、0 跨会话污染或残留事件，空闲后 `/health` 归 `in_flight=0`；
  - 非法请求返回清晰错误且紧随其后的正常请求 100% 恢复；慢消费者背压下不断连、不丢音频字节。
- **硬验收指标**：30 分钟混合压测 0 crash / 0 泄漏 / 0 串流 / 100% 故障恢复。

### NS-08｜跨端开箱即用体验（Web UI + macOS `ummmlx`）
- **输入**：真实用户打开浏览器（Web UI）或 macOS `ummmlx` 连接常驻服务，不碰任何高级设置，完整走完 NS-01 / NS-02 / NS-04 / NS-05，并执行会话导出 JSON → 清空 → 重新导入 → 断线重连。
- **理想态输出**：
  - 全程零手工模态控制、零报错、Markdown/图/视频/音频播放顺滑不闪跳、语音打断跟手；
  - 导出 → 导入 → 重连后多模态内容与历史 100% 还原。
- **硬验收指标**：Web 与 macOS 双端真人走查全过、零阻塞缺陷、会话往返 100% 无损。
